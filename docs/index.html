开黑房的正确打开方式

不为联机折腾公网 IP、端口映射和繁琐配置——一个房间码，朋友粘贴即可进房。

朋友不用装 Python

PyInstaller 打包成单文件 exe，内含运行环境；把客户端 zip 发给朋友，解压双击 start.bat 就能进房。

8 位房间码

房间码随机生成，界面上不暴露任何网络参数；同一串码在任何电脑上都推导出相同的房间身份与加密密钥——码不对，就进不来。

P2P 直连

supernode 只负责「房间登记 + NAT 打洞」，双方打洞成功即 P2P 直连，低延迟不占服务器带宽；打洞失败自动降级服务器中转。

中英双语界面

自动检测系统语言：中文系统显示中文，英文系统显示英文；也可在「工具与设置 → 语言」随时切换，老外朋友零门槛使用。

Linux 也能进同一个房

附一键进房脚本（join_room_linux.sh），Windows 房主 + Linux 好友同房间互通；下载预编译 n2n v3 edge 即可。

macOS 直接进房

Intel 与 Apple 芯片通用：一键脚本编译 n2n edge 后图形界面进房；或者完全零安装，Mac 直接连房主 IP:25565。

开源可审计

房间管理工具与部署脚本采用 MIT 协议，n2n 引擎 GPLv3、TAP 驱动 GPLv2，来源与许可全部在仓库里写清，可自行复查。

它是怎么把两台电脑变成同一个房间的

服务器由客户端自动搞定：谁能当服务器、端口通不通，程序自己判断，你只要把一串码发给朋友。

  1. 服务器只做「前台」

    不用自己部署服务器。客户端内置服务器组件：有公网 IPv4 就自动开在本机并尝试自动开端口（UPnP）；没有公网 IPv4 会自动改用公网 IPv6 直连，两边在同一个网络下还能走局域网直连。

  2. 房间码 = 房间的身份

    房主点「创建房间」时自动生成 8 位房间码，并据此推导房间身份与加密密钥；同一串码在任何电脑上算出的房间完全一致，输错一位就进不去。

  3. 进房后 P2P 直连

    双方都拿到虚拟 IP（10.x.0.x），打洞成功就直连互访；打洞失败自动降级为服务器中转，房间依然可用。

三步开黑

装上客户端，两步就能进游戏。不需要部署服务器，也不需要懂端口映射。

01

下载并安装

点上面的下载按钮拿到安装包，双击安装：会自动创建带图标的桌面快捷方式，并自带卸载程序。首次开房若弹出权限确认，点「是」即可，之后不再打扰。

02

房主点「创建房间」

客户端自动装好虚拟网卡、放行防火墙、选好服务器，几秒后状态变成「已连上」，并给出 8 位邀请码（可复制、可出二维码）。

03

好友粘贴邀请码进房

好友在「加入」框里粘贴邀请码点加入，两边都显示「已连上」后，好友进我的世界 → 对局域网开放，好友在「多人游戏」列表里直接看到你的世界；列表没刷新就手填 10.x.0.1:25565。

常见问题

几句话讲清最容易踩的坑。

家里没有公网 IP，还能用吗？

能。客户端会自己按顺序判断：有公网 IPv4 就在你电脑上开房间服务器并自动开端口（路由器开着 UPnP 就能成功，不行就提示你在路由器转发 UDP 7654）；没有公网 IPv4 就自动改用公网 IPv6 直连（大部分家庭宽带和手机流量都支持，好友不用做任何设置）；连 IPv6 也没有，两边在同一个 WiFi/路由器下还能直接走局域网。三种都不通时才会提示你换个网络或让朋友开房。

为什么不能只把 exe 发给朋友？

不用了，现在直接把安装包发给对方装上就行（绿色版 zip 也行）。exe 仍需同目录的 bin/（edge 引擎）、driver/（TAP 虚拟网卡驱动）、tools/ 才能工作，所以别只单独拷一个 exe。

双方都显示「已连接」但游戏里看不到对方？

先确认两边用的是同一条 8 位邀请码（输错一位就是另一个房间，自然互相看不见）；再确认 MC 版本与模组完全一致。仍然看不到，就在「多人游戏 → 直接连接」里填 10.x.0.1:25565，绕开局域网自动发现。

一个房间能进几个人？

官方 supernode 引擎本身不限制人数，实际体验建议控制在 8 人以内：人多时一部分流量会走服务器中转，房主的上传带宽更容易成为瓶颈。客户端也不强制限流，这一点如实说明。
